⚙ System Architecture
Agent 1: Resume Parsing Agent
Extracts structured data from PDF, DOCX, and TXT resumes using NLP + LLM
Agent 2: Skill Normalization Agent
Maps skills to canonical taxonomy (JS → JavaScript, K8s → Kubernetes)
Agent 3: Semantic Matching Agent
Vector embedding-based skill matching with weighted scoring
Orchestrator
Coordinates all agents with retry logic, batch processing, and tracing
🚀 Quick Start

1. Go to Parse Resume tab and upload a resume (PDF/DOCX/TXT)

2. View extracted data: name, skills, experience, education

3. Go to Job Matching tab to match the candidate against a job

4. See the match score, matched/missing skills, and gap analysis

5. Browse the Skill Taxonomy with 157+ skills across 12 categories
